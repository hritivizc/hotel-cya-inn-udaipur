# Hotel CYA INN (Udaipur) — QR Landing Page

This repository hosts a single-page QR landing website for **Hotel CYA INN, Udaipur (Rajasthan)**.

## Live site (GitHub Pages)

- https://hritivizc.github.io/hotel-cya-inn-udaipur/

## What this page does

- **Step 1:** Collects guest **Name** + **Phone**.
- **Step 2:** Asks the guest to:
  - Follow on **Instagram**
  - Review on **Google Maps**
- **Step 3:** Shows a success screen and the submitted details.

## Links used (from the page)

- **Instagram:** https://www.instagram.com/cya_inn
- **Google Maps:** https://maps.app.goo.gl/yYHQtL5t2ps9YioJ8
